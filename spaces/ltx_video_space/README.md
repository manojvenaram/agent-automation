# 🎬 LTX Video Studio

An AI-powered video creation studio powered by Lightricks LTX foundation models:
- **Text-to-Video**: Fast high-definition video generation from descriptive prompts.
- **Image-to-Video**: Motion animation from static source images.
- **Audio-Visual Generation (LTX-2.5)**: Unified video and synchronized audio synthesis.

Runs on Hugging Face Spaces with zero local GPU requirements.
